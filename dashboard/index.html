How the value is worked out

  • Size multiple. A token is worth a multiple of the TVL it secures, and the multiple falls as TVL grows — a small protocol's token has more headroom than a giant's. At $100M of TVL the multiple is 0.42; at $10B it is about 0.27.
  • Growth. The 7-day TVL change, clamped to −50%…+150%, feeds in at 70% of its size. A protocol growing fast is worth more than one the same size that is shrinking.
  • Maturity. A protocol that has run for years with no token is more likely to launch a valuable one than one listed last week. The factor rises from 0.55 to 1.00 over four years with no token.
  • Chain breadth. Each extra chain adds 3%, up to five extra chains. A protocol on more chains reaches more users.

An implied value is a model, not a price. It says what a token could be worth from the snapshot's own figures — TVL, growth, age with no token, chains — not what it will be. A protocol with no token recorded is not proof it will ever launch one.
